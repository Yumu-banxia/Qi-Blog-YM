# Qi-blog-ds

计算机学院企源开发者协会「博观代码・客绘星河」个人博客创意设计大赛参赛作品。

## 赛事要点

赛事面向计算机学院全体本科生，以个人博客为主题进行原创页面设计，围绕创意性、实用性、美观性展开，同时兼顾加载速度、导航清晰度与内容可读性。

报名截止时间为 2026 年 10 月 16 日 08:30，需在「到梦空间」检索「个人博客创意设计大赛」完成报名。作品以电子压缩包形式提交，命名格式为「学号 + 姓名 + 班级 + 作品名」，于 2026 年 10 月 20 日 22:00 前发送至 ljw2287327591@qq.com，并附带包含设计理念与技术实现的说明文档。

完整条款见 [docs/competition-brief.md](docs/competition-brief.md)。

## 开发环境

本机 Node.js 位于 Windows 侧（`D:\Software\nodejs`），版本 v24.19.0。在 WSL 中执行构建命令时需要使用 Windows 端可执行文件，或在 PowerShell / CMD 中直接运行。

## 提交检查清单

页面功能在目标浏览器中完成自测，压缩包命名符合「学号 + 姓名 + 班级 + 作品名」，设计说明文档随包附上，提交时间早于 2026 年 10 月 20 日 22:00。
