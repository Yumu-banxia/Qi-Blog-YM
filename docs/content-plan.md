# 内容与栏目结构

本文档确定导航栏目、页面清单与内容组织方式，作为页面实现的依据。

## 一、页面组织方式

站点采用多页文件组织。各栏目拆为独立 HTML 文件，一级导航在文件之间跳转，页内锚点不再承担栏目导航的职责。

三处理由。文章列表与详情页本身是两份文档，赛事要求也把两者列为不同视图；多页结构在 file:// 与静态托管两种环境下行为一致；把全部栏目压在单页内，会让单个文件的体积与解析量随内容增长，与首屏预算冲突。

共享的头部与尾部在每页复制一份。无构建方案下，复制是不引入运行时代价的做法。页面数量超过八页时改用一次性生成脚本，运行时不参与。

相对地址规则：根目录页面引用 `assets/...`，`pages/` 目录下的页面引用 `../assets/...`。页面之间的跳转遵循同一规则，根目录页面指向 `pages/posts.html`，`pages/` 下的页面指向 `../index.html`。

## 二、导航结构

一级导航固定四项，顺序不变。

| 导航项 | 目标文件 | 覆盖页面 |
| --- | --- | --- |
| 首页 | index.html | 首页 |
| 文章 | pages/posts.html | 文章列表、文章详情 |
| 作品 | pages/works.html | 作品陈列 |
| 关于 | pages/about.html | 个人介绍 |

当前页面对应的导航项标注 `aria-current="page"`，文章详情页沿用「文章」项。

## 三、页面清单

### index.html 首页

1. 首屏。作者定位、通往文章与作品的两个入口，以及站点星图。星图把四个栏目画成星座节点，节点下方标注各栏目承载的内容量，链接与主导航一致。星图上的内容量需要随文章与作品的增减同步更新。星图在允许动效的访问端以漂浮形式呈现：四个节点各自缓慢游走，指针靠近时被轻微吸引、移开后回位，连线为随位置变化的曲线；指针还用于高亮相关节点与连线，节点可以拖动并成为新的漂浮锚点，滚轮缩放、拖动空白处平移，双击或按 Esc 复位；低速档位、功能机档位与减少动态效果偏好下保持静态形态。
2. 精选文章。两条，每条含标题、日期与摘要。选最新两篇，与文章列表页的完整清单区分开。
3. 作品概览。三条，每条含名称、简介与技术栈。
4. 简介摘要。两到三句，附通往关于页的入口。
5. 页脚。

### pages/posts.html 文章列表

1. 页头。标题与一句说明。
2. 文章清单。按日期倒序，每条含标题、日期、摘要与标签。
3. 分页或继续加载。文章数量超过十篇时启用。

### pages/post-*.html 文章详情

1. 文章头部。标题、日期、标签。
2. 正文。静态 HTML，含标题层级、段落、代码块、引用与图片。
3. 上下篇导航。
4. 返回文章列表的入口。

文件名采用 `post-` 加英文短标题。当前三篇为 `post-no-build.html`（无构建方案）、`post-capability.html`（访问端能力分级）、`post-reader.html`（阅读增强），三者按日期倒序排列，相邻两篇互为上下篇。

上下篇导航标明「更早的一篇」与「更新的一篇」，两栏排列；只有一侧存在时该项占满整行；列表入口独立成一行。

### pages/works.html 作品陈列

1. 页头。标题与一句说明。
2. 作品清单。每条含名称、简介、技术栈与仓库地址。

### pages/about.html 关于

1. 页头。标题。
2. 个人介绍。学习方向与技术兴趣。
3. 技能与工具清单。
4. 联系方式。

## 四、内容承载方式

全部内容以静态 HTML 编写，页面脚本不参与内容生成。三处理由：脚本关闭时正文仍然可读；内容不依赖解析完成后再插入，首屏不出现闪现；能力分级中的 minimal 档位不需要为内容准备额外分支。

文章正文的书写约定：小节标题用 `h2`，其下细分用 `h3`；段落用 `p`；引用用 `blockquote`；标签集合用 `ul` 与 `li`。

代码块写作 `pre` 包裹 `code`，并在 `code` 上标注 `class="language-xxx"` 供高亮库识别语言，例如 `class="language-js"`。公式用 `$...$` 写作行内形式，用 `$$...$$` 写作独立成段的形式；`pre` 与 `code` 内部的美元符号不参与公式解析。

对照类内容用 `table` 书写，并由 `class="table-wrap"` 的容器包裹，容器上标注 `tabindex="0"` 以便键盘进入横向滚动。表格需要 `caption` 说明用途，行首表头使用 `th` 并标注 `scope`。

文章详情页额外加载 `assets/styles/article.css` 与 `assets/scripts/reader.js`，其余页面不加载这两份文件。

## 五、验收

1. 每条导航项对应唯一文件，头部与尾部在全部页面保持一致。
2. 每个区块的内容来源与更新方式明确。
3. 375、768、1440 三种宽度下无横向滚动，键盘可以完成全部导航。
