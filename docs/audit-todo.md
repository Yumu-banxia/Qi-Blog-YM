## 第一阶段：修复功能与交互问题

### P1 星图运行中切换减少动态效果后连线消失

位置：`assets/scripts/chart.js` 的 `stop()` 与 `prefers-reduced-motion` 监听。

当前 `stop()` 会移除 SVG 连线的 `d` 属性。页面载入时已经处于减少动态效果状态，脚本会提前退出，HTML 中的静态连线仍然存在；页面载入后才切换系统偏好时，`stop()` 删除连线后没有恢复步骤，星图会缺少边线。监听器也只处理切换到减少动态效果的方向。

处理要求：停止运动时保留静态连线，或按初始 SVG 数据恢复；节点与视图状态回到定义好的静态位置；明确偏好关闭后是否恢复动效，并使实现与设计说明一致。

验收：在 Chrome 中分别以减少动态效果开启和关闭状态载入；运行中切换两次；四个节点、四条连线、焦点样式与键盘操作保持可用，动效状态符合当前系统偏好。

### P1 作品灯箱补齐模态窗口焦点管理

位置：`assets/scripts/gallery.js`、`pages/works.html` 中 `#lightbox`、`assets/styles/base.css` 中 `.lightbox`。

灯箱使用 `role="dialog"` 与 `aria-modal="true"`，打开时焦点移到关闭按钮，Esc 关闭后返回触发按钮；当前没有 Tab 焦点循环，也没有暂停背景内容的键盘访问。背景滚动状态也没有随灯箱开关管理。

处理要求：打开期间限制 Tab 与 Shift+Tab 在灯箱内部循环；关闭时恢复触发按钮焦点和页面滚动状态；背景内容在灯箱打开期间退出键盘访问范围；保留关闭按钮、Esc 与背景点击三种关闭方式。旧浏览器缺少 `inert` 时使用兼容处理。

验收：仅用键盘打开灯箱，连续正向与反向 Tab；焦点始终在关闭按钮可达范围内；关闭后回到原按钮；读屏能获取对话框名称和图片替代文字；窄屏页面背景不会随灯箱滚动。

### P1 复制失败时避免播报成功

位置：`assets/scripts/reader.js` 的 `copyText()` 与代码块复制按钮回调。

剪贴板 API 拒绝后会进入 `execCommand('copy')` 回退。回退代码没有检查该命令的布尔返回值，因此某些权限受限环境下可能复制失败，却仍显示“已复制”并向读屏播报成功。

处理要求：区分复制成功与失败；检查剪贴板 API 与回退命令结果；失败时给出可读提示并保留原代码；按钮状态在成功、失败和再次操作后都能恢复。

验收：分别覆盖剪贴板成功、API 拒绝、回退返回失败与浏览器缺少 `execCommand` 的情形；可见提示与读屏状态一致。

### P1 搜索脚本与索引加载状态可恢复

位置：`assets/scripts/main.js` 的 `openSearch()`；`assets/scripts/search.js` 的 `open()`、`loadIndex()` 与 `script.onerror`。

快速连续点击搜索入口时，`main.js` 在 `SiteSearch` 建立前可能重复插入 `search.js`。搜索面板将状态设为“正在载入索引”后，随即调用 `render([], '')`，载入提示被“输入关键词”覆盖。索引请求失败后将 `entries` 设为空数组，后续打开面板会按已经完成处理，当前会话里缺少重新载入机会。

处理要求：统一管理搜索脚本的加载中状态与已加载实例；保留真实的索引加载提示；区分成功、失败和空结果；失败后允许用户重新尝试，避免重复绑定事件。

验收：快速连续触发搜索只初始化一份脚本；慢速网络下显示加载状态；索引失败后可再次请求；正常搜索、键盘选择、Esc 关闭及焦点归还均正常。

## 第二阶段：兼容性与降级边界

### P1 保留最低档位的跳转主内容入口

位置：`assets/styles/lite.css` 中 `.skip-link` 规则。

兜底样式将 `.skip-link` 与隐藏的图标按钮一并设为 `display: none`。这样最低档位的键盘访问者无法使用页面首部的“跳到主要内容”链接。

处理要求：兜底模式下继续提供可聚焦、可见的跳转主内容入口；单独处理不应显示的搜索、主题和菜单按钮。

验收：模拟最低档位并禁用脚本，键盘首个可聚焦项能跳至 `main`，导航和正文仍可读。

### P1 让能力检测、功能门控与说明文档一致

位置：`assets/scripts/capability.js`、`docs/plan.md`、`docs/design-note.md`、`pages/post-capability.html`。

`Capability.env` 记录了 `intersectionObserver`、`blur` 与 `canvas`，当前档位判断只把自定义属性、`matchMedia`、`requestAnimationFrame` 作为运行时缺失条件。`canvas` 检测只确认存在 `getContext` 方法，没有确认上下文能否创建；站点星图使用 SVG，也没有 Canvas 功能依赖。`Capability.load()` 当前没有调用点。文章中“任一项缺失”的说明与实现边界不完全一致。

处理要求：逐项确认每个接口对应的功能；核心能力缺失时再降低档位，非核心接口缺失时关闭对应增强；删除无调用的检测与接口，或补齐明确调用方；修正各档原因值，令 UA、硬件、网络和运行时信号可分别辨认。同步更新文档和文章中的判定描述。

验收：为各信号建立输入与期望结果表；缺少单项可选 API 时，正文、导航和其余增强仍正常；`data-cap`、`data-cap-reason` 与实际降级内容一致。

### P1 核对静态托管的根目录与子目录访问

位置：`404.html` 中以 `/` 开头的资源与页面地址；项目没有正式部署地址。

`404.html` 的样式、脚本、图标、清单和导航均以站点根目录为基准。如果发布地址使用 GitHub Pages 项目站点形式，例如 `/<repository>/`，这些地址会指向域名根目录，可能导致 404 页面缺少样式和功能。

处理要求：以本地 HTTP 服务分别模拟域名根与项目子目录；使用经过验证的相对地址或明确的站点前缀策略，令两种目录结构下的资源和页面跳转均可访问。

验收：在根目录与项目子目录两种本地模拟环境访问首页、文章、作品截图、清单、图标和 404 页面；逐项确认资源返回成功。

位置：`docs/plan.md` 的兼容性记录与验收章节。

现有说明记录了 Chrome、Firefox 与功能机 UA 模拟等检查；文档同时指出 Edge 未单独完成无头截图检查，功能机实测样本有限。UA 模拟可以验证分支条件，无法代替旧设备真实浏览器检查。

### P3 复查星图动效强度和说明

位置：`assets/scripts/chart.js` 文件顶部注释、指针力场参数与复位动画；`docs/design-note.md`。

代码顶部注释称指针会“把近旁节点推开”，实际 `pointerForce()` 按指针到节点的方向施加吸引力；项目既有需求为轻微吸引。文案与计算逻辑表述相反，容易引导后续调整偏离现有要求。

处理要求：注释与实际方向统一；在鼠标缓慢移动、快速移动、停留、拖动节点和双击复位时检查运动幅度；延续节点独立漂浮和曲线连续的结构。任何动效改动须同时检查减少动态效果与低端档位。

验收：指针只产生轻微吸引；无节点选中文字或误触链接；双击复位缓和；各节点独立运动；连线经过节点时保持平滑。

### P3 统一排版与状态细节

位置：`assets/styles/tokens.css`、`assets/styles/base.css`、`assets/styles/article.css`。

在最终视觉复核中检查 360、768、1440 像素窗口以及明暗主题；检查文章长标题、代码块、公式、图片、表格、页头导航和搜索面板的断行、滚动与遮挡。现有设计令牌使用视口相关字号计算，评估其在固定阅读宽度、窄屏和浏览器缩放下的可读性。

验收：无文字遮挡、布局跳动和非预期横向滚动；站内链接状态、焦点样式、代码块折叠与公式颜色保持一致。
