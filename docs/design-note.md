# 设计说明

本文档说明作品的设计理念、视觉系统与技术实现，供赛事评审与后续维护参考。

## 一、作品概述

作品名为 Qi-blog-ds，是一套个人博客站点，包含首页、文章列表、三篇文章正文、作品陈列与个人介绍五类页面。产出为纯静态文件，双击 `index.html` 即可完整浏览，无需安装依赖，也无需启动服务。

## 二、设计理念

### 把站点结构画成星图

首屏不放大幅配图，而是把四个栏目画成一组星座节点：节点之间有连线，每个节点下方标注该栏目承载的内容量，例如「文章 3 篇」「作品 3 项」。这张星图既是导航入口，也是本站主题的说明——站点的结构本身成为第一屏的视觉主体。

选择这一形式有两点考虑。星河是与赛事主题呼应的意象，但单纯的星点背景只能算装饰；把栏目关系画成星图，图形就承载了真实信息，浏览者看一眼便能知道站点由哪几个部分组成、各自有多少内容。装饰与结构合为一处，页面也就不需要额外的横幅图或插画。

星图只在首页出现一次。其余页面回到安静的单栏或双栏阅读版式，避免同一手法反复使用而失去分量。

### 阅读优先

文章页的正文行宽控制在 36rem，基准字号 17 像素、行高 1.75，小节标题的行高为 1.22 并启用两行均衡断行。宽屏下目录独立成一栏并随滚动停留在视口上方，正文保持在适读宽度，视线不必在整屏宽度内来回移动。

### 节制

页面上的动效集中在四处：首屏星点的缓慢漂移、星图连线在载入时的绘制、列表项滚入视口时的位移（8 像素、400 毫秒，同组条目按 70 毫秒步进错开，上限 210 毫秒），以及指针在星图内的引力响应。前三者与指针交互中的节点位移、观测星跟随只改 `transform` 与 `opacity`，由合成层承担；连线弯曲重写路径数据，数量限定在四条。系统偏好减少动态效果时，全部动效关闭，内容原样呈现。

### 降级属于设计的一部分

站点按访问端能力划分为四档，低端设备上关闭页头模糊、动效与第三方渲染库，功能机改读另一份不依赖自定义属性与弹性布局的样式表。完整设计效果由现代设备承担，但内容与导航在任何档位下都保持可读、可用。

## 三、视觉系统

### 配色

两套配色，浅色为月白底、墨色正文，深色为夜空底、星尘正文，两套都以靛蓝或天青承担链接，以星辉琥珀承担强调。文本对比度取自实际令牌值。

| 组合 | 浅色 | 深色 |
| --- | --- | --- |
| 正文对底色 | 17.77 | 16.29 |
| 次要文字对底色 | 6.77 | 7.63 |
| 链接对底色 | 6.65 | 9.31 |
| 填充按钮上的文字 | 7.76 | 11.97 |

配色由 `assets/styles/tokens.css` 中的自定义属性定义，明暗两套随 `data-theme` 切换，首屏由 `capability.js` 同步解析，避免刷新时出现明暗闪烁。移动端浏览器界面底色由 `main.js` 同步为页面底色。

### 字体

正文使用系统字族，代码与元信息使用系统的等宽字族，不下载任何字体文件，字体相关请求为 0 字节。

显示层级同样使用系统字族，这是本站在字体上的取舍：中文显示字体体积以兆字节计，自托管会直接冲垮首屏预算，拆分子集又需要构建步骤，与无构建方案冲突。层级改由字号阶梯、字重与行距建立，字号分为七档，全部以 `rem` 与 `clamp()` 定义，随视口宽度平缓变化。低端档位换用 Arial 与 Helvetica 字族，取舍同样来自体积与可预测性。

### 版式

容器宽度上限 72rem，正文行宽上限 36rem，区块纵向间距为 3rem 到 5.5rem 之间的流式值。响应式断点取 48rem、60rem 与 64rem 三处，分别对应上下篇导航分栏、首页首屏分栏与文章页目录分栏。

### 图形

星点由 `radial-gradient` 平铺生成，点位取 1 像素与 1.5 像素并采用硬边收束，不产生光斑；平铺尺寸与位移量都取整数值，循环处不留接缝，漂移交给 `transform` 完成。

星图为内联 SVG，路径长度用 `pathLength` 归一化后按顺序绘制，描边使用 `vector-effect: non-scaling-stroke`，因此任意尺寸下线条粗细一致。节点标记是一枚四角星，同样以内联 SVG 绘制：与实心圆点相比，它更接近星图的语言，也避免用零偏移色环制造光晕。作品页另附三张实际截图，由无头浏览器以真实渲染结果采集并转为 WebP，宽度 1200 像素，合计约 150 KB，全部懒加载并标注宽高；点击后进入放大查看，Esc 或点击背景退出，焦点回到触发按钮。
### 星图交互

首页星图的四个节点各自漂浮。每个节点以自身的基准位置为锚，受两条低频扰动分量驱动，并受回中弹力与阻尼约束，相位与振幅各不相同；九秒窗口内的实测游走幅度为 6 到 15 像素，位移方向互不关联。

指针在画布内移动时形成力场，近旁节点被轻微吸引。作用半径为 180 像素，力度随距离平方衰减，单次位移上限 34 像素，并按指针的移动方向追加一点拖尾推力，因此指针扫过时节点的位移与方向都随指针变化。指针停在画布中部两点六秒，半径内的三个节点与指针的距离分别缩短 7、10 与 17 像素，方向均朝向指针；指针移开后节点在弹力作用下回到基准位置。指针停在某个节点上时暂停该处力场，节点保持稳定，位移不超过 3 像素，点击不受干扰。节点与画布都不可被拖拽为链接，拖动过程也不产生文本选择。

指针还承担高亮与操作：悬停或键盘聚焦某个节点时，该节点与相连的两条连线保持原样，其余降到三成不透明度；节点可以拖动，位置写回该节点的 `--x` 与 `--y`，成为新的漂浮锚点；滚轮以指针位置为中心放大，画布可放大到 1.8 倍，放大后可拖动空白处平移视图，双击或按 Esc 回到初始视图。页面中没有跟随指针的装饰元素。

四条连线用三次贝塞尔绘制。每个节点的切线取前后两个邻点的连线方向，也就是曲线穿过该节点时的走向；起点控制点沿该切线向前偏移，终点控制点沿终点的切线向后偏移，偏移量取线段长度的 30%。相邻两条边在同一节点处的进出方向因此完全一致，四段边连成一条平滑的闭合曲线，节点移动时形状连续变化，不会翻转或出现折角。逐帧工作只有四个节点的位移计算，连线每两帧重算一次；星图离开视口或页面转入后台时暂停；系统偏好减少动态效果时终止漂浮并让节点回到基准位置；低速档位与功能机档位下脚本不启用，星图保持静态。

节点位置与连线端点由同一份坐标推导，窗口尺寸变化后不会出现线与星点错位。运动由时间驱动，与指针状态无关；逐帧工作只有四个节点的位移计算，连线每两帧重算一次。星图离开视口或页面转入后台时暂停；系统偏好减少动态效果时终止漂浮并让节点回到基准位置；低速档位与功能机档位下脚本不启用，星图保持静态，键盘操作与无脚本环境的导航能力不受影响。

缩放与平移由自研的视图变换承担，未引入图形库。选型阶段比较了两个候选：d3-zoom 连同 drag、selection、transition、interpolate、color、ease、timer 等依赖共 9 个文件、约 63 KB（min 构建）；`@panzoom/panzoom` 单文件 10.1 KB 且无依赖，但其包含约束以元素小于容器为前提，与星图"元素与容器同尺寸"的布局前提冲突，实测滚轮缩放与平移被约束拦下。两者都未进入请求队列。

## 四、技术实现

### 不使用构建步骤

赛事作品以压缩包提交，评审可能直接双击打开页面。这种打开方式下页面处于 `file://` 环境，ES module 受跨源策略限制，外部模块与本地数据文件都会读取失败，因此脚本全部使用 classic script，资源引用一律使用相对地址。构建产物常以站点根目录为前提使用绝对地址，本地打开时会全部取不到，这一条排除了若干静态站点生成器。

省去构建换来的是打开即用与更小的体积，付出的是模板手工同步与依赖手工升级。项目规模为一位作者、七个页面时，这一取舍成立。

### 访问端能力分级

`assets/scripts/capability.js` 在首屏同步执行，从三处取信号：User-Agent 中的功能机与老式移动浏览器特征、硬件与网络线索（逻辑核数、设备内存、省流模式、2G 级连接）、运行时接口的可用性（自定义属性、`matchMedia`、`requestAnimationFrame`、`IntersectionObserver`、`backdrop-filter`、画布上下文）。

| 档位 | 判定条件 | 允许项 |
| --- | --- | --- |
| high | 逻辑核数 8 以上，内存 4 GB 以上，未偏好减少动态效果 | 全部动效与增强 |
| medium | 未命中其他条件的现代设备 | 动效、模糊、按需脚本 |
| low | 受限 UA、双核以内、内存 1 GB 以内、省流模式或 2G 级连接 | 静态内容与基础表现 |
| minimal | 功能机 UA，或缺少自定义属性等基础接口 | 静态内容 |

判定结果写入根元素的 `data-cap`，来源写入 `data-cap-reason`。样式按属性选择器分支处理降级，脚本通过 `Capability.allow(name)` 查询单项能力，通过 `Capability.load(name, src)` 决定是否注入高开销脚本；未获允许时资源不进入请求队列。`minimal` 档位额外挂载 `assets/styles/lite.css`，该样式表不使用自定义属性、弹性布局、网格与逻辑属性。

### 阅读增强

文章页额外加载 `assets/styles/article.css` 与 `assets/scripts/reader.js`，提供目录、阅读进度、字号切换与代码块操作。

目录由脚本扫描正文的二级与三级标题生成，标题不足三条时不生成，避免为短文制造冗余结构。阅读进度条高度 2 像素，位移由 `transform: scaleX()` 承担，滚动回调合并到 `requestAnimationFrame`。字号分为三档，正文、标题、代码与公式按同一比例缩放。

代码块补上语言标注、折叠与复制。折叠阈值取 16 行；复制优先使用异步剪贴板接口，不可用时回退到临时文本域与 `execCommand`，在本地文件环境下同样有效；代码块可横向滚动，因此补上 `tabindex` 以便键盘进入。

公式与代码高亮按需加载：代码高亮只在页面存在代码块时请求，公式渲染只在正文纯文本命中公式分隔符时请求，判定时跳过 `code` 与 `pre` 内部文本。KaTeX 与 highlight.js 以本地文件形式放在 `assets/vendor/`，随站点一起分发。

### 站内搜索

导航栏提供站内搜索，打开方式为按钮、斜杠键或 Ctrl+K，关闭方式为 Esc、关闭按钮或点击遮罩。索引文件 `assets/data/search-index.js` 由文章页面提取生成，含标题、日期、标签、摘要与正文纯文本，大小 6.8 KB，首次打开面板时才按需请求，不进首屏。

搜索脚本与索引都按需加载：页面上只保留一个按钮，点击或按快捷键时才请求 10.3 KB 的脚本，脚本就绪后再取 6.7 KB 的索引，首屏不为搜索付出体积。

匹配按字段加权：标题 6 分、标签 4 分、摘要 2 分、正文 1 分，逐词求交，命中片段以高亮标注，结果按得分排序并限制在八条。结果可用方向键选择、回车进入，面板内 Tab 循环不逸出，关闭后焦点回到触发按钮。无脚本与最低档位下搜索入口隐藏。

### 性能预算与实测

| 维度 | 预算 | 实测 |
| --- | --- | --- |
| 首屏 HTML 与 CSS | 未压缩 120 KB 以内 | 首页 30.8 KB |
| 页面自带脚本 | 未压缩 40 KB 以内 | 全站页面 11.0 KB，首页另加 21.3 KB，文章页另加 14.5 KB |
| 第三方渲染库 | 命中内容时才加载 | 文章页按需，highlight.js 约 129 KB、KaTeX 约 273 KB 与字体约 296 KB |
| 单页 DOM 节点 | 1500 以内 | 最多 360 |
| 横向溢出 | 0 | 360、753、1425 三种宽度下均为 0 |

首屏资源（HTML、CSS 与页面脚本，未压缩）实测：首页 63.6 KB，文章列表、作品、关于三页在 37.0 KB 到 38.0 KB 之间，文章详情页在 62.2 KB 到 64.3 KB 之间。gzip 后首页为 20.5 KB，文章列表与作品、关于三页为 12.7 KB 到 12.8 KB，文章详情页在 21.1 KB 到 21.8 KB 之间。体积统计按 1 KB 等于 1024 字节换算。

### 兼容性

布局与交互的基线为 Chrome 与 Edge 105 以上、Firefox 110 以上、Safari 15.4 以上。在此之上使用若干渐进增强项，取值不支持时按声明回退，不影响页面成立：`text-wrap: balance` 与 `text-wrap: pretty`、`color-mix()`、`backdrop-filter`、`mask-image`、`aspect-ratio`。样式表中的回退写法保证旧引擎读到前一条声明。

### 无障碍

跳转链接置于文档首位，键盘可完成全部导航；当前页面在导航中标注 `aria-current`；折叠按钮同步 `aria-expanded`，代码复制结果由独立状态区播报；焦点样式使用 2 像素描边并留出偏移；打印样式下展开折叠的代码块并隐藏交互组件。阶段五核对时五个页面的无障碍审计均无失败项。

### 浏览器界面元素

除自绘界面之外，随浏览器而来的部分也纳入配色：文本选中的底色取强调色的低透明度形式，插入符号使用强调色，正文与表格的横向滚动条由 `scrollbar-color` 与 `scrollbar-width` 指定颜色与宽度。这三处默认外观不来自本站的设计系统，统一之后观感才连续。标签页图标为内联 SVG 四角星，浅色环境下取深色，深色环境下取琥珀色，随系统配色切换，体积 330 字节。
### 打印与导出

打印时页面切换为纸质阅读形态：导航、主题按钮、跳转链接、星图与进度条隐藏，链接统一为黑色并带下划线，按钮与标签去掉边框与底色，页头改为静态定位，区块间距收窄，折叠的代码块展开，文章页的目录与工具条不进入纸张。待入场元素在打印媒体下不保留初始状态，导出为 PDF 时内容完整。
## 五、运行方式

直接双击 `index.html` 即可浏览全部页面。如需以静态托管方式查看，在项目根目录执行 `python -m http.server` 后访问本地端口，两种方式行为一致。

## 六、已知限制

1. 待入场列表项依赖 `IntersectionObserver` 判定，以不滚动的整页截图工具采集时，未进入视口的元素保持隐藏状态；正常浏览、打印与减少动态效果偏好下不受影响。
2. 页头与页尾在每页各存一份，改动需要逐页同步；页面数量超过八页时改用一次性生成脚本。
3. 文章正文使用示例性技术内容，个人身份信息与提交信息按赛事要求另行补全。
