# 项目规划

本文档确立个人博客作品的技术底座、目录结构与开发顺序。开发顺序遵循一条原则：功能与流畅性优先，视觉打磨置于末位。

## 一、技术底座

### 选型结果

| 层次 | 选型 | 引入方式 |
| --- | --- | --- |
| 页面结构 | 语义化 HTML5，静态多页面 | 无 |
| 样式 | 原生 CSS，自建设计令牌与组件类 | 无 |
| 脚本 | 原生 JavaScript，classic script | 无 |
| 图标 | Lucide | SVG 内联，按需复制 |
| 代码高亮 | highlight.js 11.12.0 | 文章页按需加载，本地 vendor |
| 公式渲染 | KaTeX 0.19.0 | 文章页按需加载，本地 vendor |
| 星河背景 | CSS 渐变与关键帧动画 | 无 |
| 构建 | 无构建步骤 | 无 |

第三方库以本地文件形式放入 `assets/vendor/`，随站点一起分发，file:// 环境同样可用。加载时机由 `assets/scripts/reader.js` 判断：页面存在代码块或公式时才请求对应脚本，设备档位为 low 与 minimal 时跳过。渲染库不进入首屏请求队列。

### 采用依据

1. 流畅性。无框架运行时，首屏开销集中在 HTML 与 CSS。动画只使用 transform 与 opacity，交由合成层处理，重排与重绘的出现面降到最小。
2. 兼容性。classic script 与相对地址的组合，使页面在 file:// 与静态托管两种环境下都能运行。ES module 在 file:// 下受跨源策略限制，外部模块与本地区块数据读取都会失败，因此不作为加载方式。
3. 赛事契合。赛事点名 HTML、CSS、JavaScript 三项技术，原生实现与技术说明一一对应。
4. 环境契合。本机 Node 位于 Windows 侧，构建链调用成本偏高，无构建方案在开发与验证环节更轻便。

### 未采用项

| 方案 | 未采用原因 |
| --- | --- |
| Vue、React、Svelte | 博客交互密度低，运行时开销超过收益 |
| Element Plus、Ant Design、Bootstrap | 默认观感趋同，体积与创意评分不匹配 |
| Tailwind CSS | 要取得可接受的体积，必须引入构建步骤 |
| Astro | 构建产物使用绝对地址，file:// 打开时资源加载失败 |

### 能力分级与降级

页面按访问端的实际条件划分四档，由 `assets/scripts/capability.js` 在首屏同步判定，结果写入 `data-cap`，供样式与脚本共同读取，并暴露为 `window.Capability`。

判定输入包含三组信号：User-Agent 中的功能机与老式移动浏览器特征、硬件与网络线索（逻辑核数、设备内存、省流模式、2G 级连接），以及运行时接口的可用性。运行时接口分为核心与增强两组：`document.querySelector`、`window.addEventListener`、自定义属性、`matchMedia`、`requestAnimationFrame` 缺失时判最低档；`IntersectionObserver`、`ResizeObserver`、`PointerEvent` 缺失时只关闭对应增强，档位不变。

| 档位 | 判定条件 | 允许项 |
| --- | --- | --- |
| high | 逻辑核数 8 以上且内存 4 GB 以上 | 全部动效与增强 |
| medium | 未命中其他条件的现代设备 | 动效、模糊、按需脚本 |
| low | 受限 UA、双核以内、内存 1 GB 以内、省流模式或 2G 级连接 | 静态内容与基础表现 |
| minimal | 功能机 UA，或缺少核心运行时接口 | 静态内容 |

high 与 medium 之外，`data-motion="reduced"` 生效，动画与过渡关闭，平滑滚动同步关闭。minimal 档位额外挂载 `assets/styles/lite.css`，该样式表不使用自定义属性、弹性布局与网格，保证功能机上仍能正确排版。

脚本侧通过 `Capability.allow(name)` 查询单项能力。未获允许时不发起请求，资源不会进入请求队列。

## 三、开发阶段

### 阶段一 技术底座

确定选型、目录结构与脚手架，建立开发与验证方式。产出为本文档与可运行的页面骨架。

验收标准：以 file:// 与静态托管两种方式打开首页，样式、脚本与主题切换均正常。

### 阶段二 内容与栏目结构

确定导航栏目、页面清单与内容组织方式。文章内容以静态 HTML 编写，不使用运行时解析，避免首屏出现内容闪现。

验收标准：页面清单与栏目关系完整，每页的内容职责清晰。

### 阶段三 页面与导航骨架

搭建各页面的语义化结构，完成响应式布局与导航，处理共享头部与底部的重复片段。

验收标准：375、768、1440 三种宽度下无横向滚动；键盘可以完成全部导航。

### 阶段四 内容模块与交互

实现文章列表与详情、作品陈列、个人介绍等模块，补充滚动出现动画与导航高亮。

验收标准：各页面内容完整、链接互通，滚动过程无掉帧。

### 阶段五 性能、兼容性与无障碍

在目标浏览器中逐项验证，核对首屏体积与渲染指标，检查焦点样式、ARIA 属性与颜色对比度。

验收标准：预算表内各项达标，Lighthouse 无障碍评分不低于 90。

### 阶段六 视觉打磨

调整设计令牌的配色、字体与间距节奏，补充星河主题的纹理与装饰元素。本阶段处于末位，前序阶段未完成时不进入。

第一轮已完成的内容：

1. 配色分为两套。浅色为月白底、墨色正文、靛蓝链接与星辉琥珀强调；深色为夜空底、星尘正文、天青链接与同色强调。明暗两套的正文对底色分别为 17.77 与 16.29，次要文字为 6.77 与 7.63，链接为 6.65 与 9.31，填充按钮上的文字为 7.76 与 11.97，均在 4.5 以上。
2. 星河装饰落在首屏。两层星点由 `radial-gradient` 平铺生成，位移量与平铺尺寸取整以保证循环处无缝，漂移由 `transform` 承担，周期分别为 240 秒与 312 秒。降级沿用既有的档位与动效门控，low 与 minimal 不播放动画，minimal 保留静态星点。
3. 排版节奏重排。正文基准字号 17 像素，行高 1.75，标题行高 1.22 并启用 `text-wrap: balance`，正文行宽收到 36rem，区块间距改为流式值，日期改用等宽数字。
4. 记录项 1 已处理。`a:visited` 的颜色声明与 `--color-link-visited` 令牌移除，站内链接不再随访问变色，站名因伪类覆盖导致的变色一并消失。首屏入口按钮的强调色改由 `--color-accent` 承担，正文目录的当前项改用链接色。

第二轮已完成的内容：

1. 首屏重做。原首屏为大标题加两个入口按钮，右侧留白偏多。改为左文右图的组合：左侧是作者定位与两个入口，右侧把四个栏目画成星座节点，节点下方标注各自的内容量（文章 3 篇、作品 3 项），连线在载入时按顺序绘制。星图同时是一处导航，链接与主导航一致，图形因此承担信息而不是装饰。
2. 内容替换。全部占位文案换成可核对的技术内容：三篇文章分别说明无构建方案、访问端能力分级与阅读增强；作品页列出本站、能力分级模块与阅读增强管线三项，链接指向仓库内对应文件；关于页补上学习方向、技能清单与联系方式。原 `pages/post-sample.html` 模板由 `post-reader.html` 承接，前者的占位内容不再保留。
3. 文章页版式。宽屏下目录移入左侧栏并随滚动停留，正文回到 36rem 的适读宽度；上下篇导航改为两栏卡片，分别标注「更早的一篇」与「更新的一篇」；打印样式隐藏工具条、目录与进度条，并展开折叠的代码块。
4. 细节修补。正文小节标题补 `scroll-margin-top`，目录跳转不再被固定页头遮挡；回到顶部按钮在动效受限时改为瞬时定位；复制结果由独立状态区播报；正文补表格样式，窄屏由外层容器承担横向滚动；元信息分隔由居中小圆点改为细线；补 `theme-color` 与选中色；能力分级脚本中未被使用的 `codeHighlight` 项移除。

记录项的收敛情况：

1. 已处理。站内链接访问后变色的问题随 `a:visited` 颜色声明与 `--color-link-visited` 令牌一并移除。
2. 记录在案。待入场列表项依赖观察器判定，以不滚动的整页截图采集时，未进入视口的元素维持隐藏状态。本轮把判定边界由视口底部收缩 8% 调整为 2%，同时保留打印与减少动态效果两条兜底；正常浏览下元素进入视口即显示。整页截图工具不滚动页面，观察器不会触发，属于采集方式带来的现象。

第三轮已完成的内容：

1. 站点图标。新增内联 SVG 图标，浅色环境下取深色四角星，深色环境下转为琥珀色；七个页面的头部均引入，标签页与书签栏不再出现空白图标。

3. 分享与结构化数据。七个页面补入 og:site_name、og:type、og:title、og:description 与 og:locale；三篇文章另加 BlogPosting 结构化数据，含标题、发布日期、语言、作者与所属站点。
4. 细节修正。上下篇导航只有一侧存在时，条目留在所属列；滚动条配色选择器组去掉非滚动容器；能力分级脚本移除未被读取的能力项；待入场处理去掉不可达的兼容分支。

仓库根目录新增 `.gitattributes`，文字文件统一以 LF 存储，避免在 Windows 与 WSL 之间切换时出现行尾抖动。
第四轮已完成的内容：

1. 星图改为指针交互。指针作为引力源，连线朝指针弯曲，节点按各自深度位移，近距节点转为活跃星，落点显示跟随的观测星；指针移出后数值缓动归零，连线回到直线。
2. 交互脚本单独成文件 `assets/scripts/chart.js`，只在首页引入，8.1 KB（gzip 2.7 KB）。脚本依次判断星图是否存在、能力档位是否允许动效，低速与功能机档位直接返回。
3. 降级条件完整。系统偏好减少动态效果时脚本不启用；减少动态效果在运行中开启时撤销交互并回到静态星图；星图离开视口或页面转入后台时暂停逐帧更新。
4. 节点深度写在样式表的 `--depth` 中，脚本读取同一份数值用于连线端点换算，节点位移与端点位置保持一致。

第四轮的核对结果：以调试端口派发真实鼠标事件，指针移到作品节点时归一化坐标为 0.72、活跃节点为作品、相连连线 2 条加亮、四条连线均为曲线；指针移到首页节点时活跃节点正确切换；指针移出星图后归一化坐标回到 0.0000、观测星不可见、连线回到直线。功能机 UA 与减少动态效果两种条件下脚本均未启用，星图保持静态。首页首屏资源因此增至 48.6 KB（gzip 15.7 KB），仍在预算内；七个页面在三种宽度下共二十一组测量的横向溢出仍为 0。
第五轮已完成的内容：

1. 星图改为图谱式交互。指针悬停或键盘聚焦某个节点时，该节点与相连连线保持，其余退到背景；节点可拖动，位置写回 `--x` 与 `--y`，连线端点随之重算；位移超过 4 像素后的松手不触发跳转。
2. 画布支持放大与平移。滚轮以指针为中心缩放，上限 1.8 倍；放大后拖动空白处平移视图；双击或按 Esc 回到初始视图；观测星按当前比例抵消缩放，不随画布一起放大。
3. 组件库调研与取舍。候选为 d3-zoom 与 `@panzoom/panzoom`。d3-zoom 连同 drag、selection、transition、interpolate、color、ease、timer 共 9 个文件、约 63 KB（min 构建）；`@panzoom/panzoom` 单文件 10.1 KB、无依赖，但其包含约束以元素小于容器为前提，与星图布局冲突，实测滚轮缩放与平移被拦下。两者均未引入，缩放平移改为自研，未增加请求。
4. 缺陷修补。节点拖动不再带动画布位移；拖动在指针抬起或取消时可靠结束；连线端点与节点位置由同一份坐标推导，窗口尺寸变化后不再错位；页面隐藏与恢复的逻辑把暂停与终止分开，避免恢复后交互失效；首页脚本引入缺失导致交互未生效的问题一并修复。

第五轮的核对结果：以调试端口派发真实鼠标与滚轮事件，节点拖动后位置由 86% 与 52% 变为 74% 与 64.5%，画布变换保持单位矩阵；滚轮两次后比例为 1.2996、观测星抵消系数为 0.7695，放大后拖动空白处的平移量为 29.85 与 -24.09 像素；双击与 Esc 均回到单位变换；悬停节点时聚焦 1 个、淡化 3 个，相连连线加亮 2 条；单击节点正常跳转到文章列表。功能机档位与减少动态效果两种条件下，画布变换、抵消系数与聚焦状态均未写入，脚本未启用。三种宽度下共二十一组测量的横向溢出仍为 0。
第六轮已完成的内容：

1. 节点改为独立漂浮。每个节点以基准位置为锚，受低频扰动、回中弹力与阻尼共同作用，相位与振幅各不相同，位移方向互不关联；实测十秒内四个节点分别移动 4 到 12 像素，相邻一步不超过 2 像素。
2. 连线改为平滑曲线。四条连线用三次贝塞尔绘制，控制点沿同侧法线偏移线段长度的 16%，随节点位置连续变化。
3. 去掉与指针强绑定的表现。移除跟随指针的观测星与节点视差位移，指针只用于高亮、拖动节点、缩放与平移；指针移动不再改变节点位置。
4. 拖动节点后以新位置为锚继续漂浮；减少动态效果开启时终止漂浮，节点回到基准位置；运动由时间驱动，与指针状态无关，页面隐藏或星图离开视口时暂停。

第六轮的核对结果：以调试端口连续采样十二次（约十秒），四个节点均在移动且方向各异，单步位移不超过 2 像素，指针停在星图内时节点照常漂浮；四条连线均为曲线，页面中不存在跟随指针的元素；悬停时高亮 1 个节点、淡化 3 个、加亮 2 条连线；拖动节点后 `--x` 与 `--y` 写为 62% 与 29.63%，拖动态无残留，画布变换保持单位矩阵；滚轮放大到 1.14 倍，Esc 复位为单位变换。
第七轮已完成的内容：

1. 提高漂浮幅度。扰动幅度与周期重新取值，九秒窗口内四个节点各游走 6 到 15 像素，肉眼可辨。
2. 加入指针力场。指针在画布内移动时，200 像素范围内的节点被推开，力度随距离平方衰减，单次位移上限 60 像素，并沿指针移动方向追加推力；指针移开后节点在弹力作用下返回基准位置。
3. 指针停在节点上时暂停该处力场，节点保持稳定，避免点击被推开干扰。
4. 首页的脚本引入加版本参数，避免浏览器缓存旧脚本导致交互未生效。

第七轮的核对结果：指针扫过画布中部时四个节点分别被推开 13、30、57 与 32 像素，方向均背离指针；指针移开三秒后与基准的距离由 24 至 64 像素降到 14 至 27 像素；指针停在节点上时位移不超过 3 像素；悬停高亮 1 个节点、淡化 3 个、加亮 2 条连线；减少动态效果与功能机档位下节点偏移均为 0。三种宽度下共二十一组测量溢出为 0。首页首屏 57.2 KB（gzip 18.3 KB）。

## 五、验证方式

1. 静态托管。在项目根目录启动静态服务器，浏览器访问本地端口。

## 第二轮检查与修正

`docs/audit-todo.md` 列出六个阶段的修正项。以下按阶段记录修改内容与核对结果。核对以无头 Chrome 经 DevTools 协议执行，页面为本地 `file://` 打开。

### 第一阶段 交互缺陷

1. 星图停用后连线丢失。原 `stop()` 会删除四条连线的 `d` 属性，页面载入后再切换到系统减少动态效果偏好就会出现缺边；改为停用时按静止后的节点位置重算并保留连线。监听器不再解绑，`enabled` 为假时各处理函数直接返回，偏好改回允许动效时重新启用漂浮。载入时即处于减少动态效果的情况也走同一条路径，不再直接跳过脚本。停用状态下方向键与 Home 复位改为瞬时落位，窗口尺寸变化不再重写画布变换。
2. 灯箱缺少模态窗口的焦点约束。打开时背景各级内容置为 `inert`（缺少支持时退回 `aria-hidden`），页面滚动暂停并按滚动条宽度补偿；Tab 与 Shift+Tab 在对话框内循环，Esc 关闭后归还触发按钮焦点并还原滚动状态。
3. 代码复制反馈与实际结果脱钩。`execCommand('copy')` 的返回值原先被忽略，权限受限时仍显示「已复制」；现按返回值区分成功与失败，失败时按钮显示「复制失败」并播报提示，两者共用一套复位流程，连续点击不叠加定时器。
4. 搜索加载状态可恢复。搜索脚本加载期间不再重复注入；索引请求失败后回到可重试状态并移除失败的脚本节点，重新打开面板或再次输入时重新请求；载入提示不再被占位文案覆盖。

第一阶段的核对结果：十六项检查全部通过。星图在载入即减少动态效果、运行中切到减少动态效果、再切回允许动效三种情形下连线均为四条，位移归零后能恢复漂浮；灯箱打开后页头为 `inert`、滚动锁定、焦点落在关闭按钮，Tab 正反向均留在对话框内，Esc 关闭后焦点回到触发按钮且滚动还原；复制失败与成功两条路径的按钮文案与播报文本一致，两秒内复位；搜索入口连续三次触发只注入一份脚本，索引请求失败后提示可重试，重新打开可正常载入三篇索引并返回检索结果。全程无页面脚本错误。


### 第二阶段 兼容性与降级边界

1. 最低档位的跳转链接被隐藏。`assets/styles/lite.css` 原先把 `.skip-link` 与图标按钮一并设为 `display: none`，键盘访问无法跳到主内容；现在兜底样式只隐藏搜索、主题与菜单按钮，跳转链接改为常驻可见，并覆盖主样式表留下的绝对定位。
2. 能力分级与实际判定对齐。`capability.js` 原先记录 `backdrop-filter` 与画布上下文两项信号，两者都不参与判定，`Capability.load()` 也没有调用方；现改为核心接口与增强接口两组，核心组缺失判最低档，增强组缺失只关闭对应功能。`data-cap-reason` 细分为 `legacy-ua`、`limited-runtime`、`constrained-ua`、`network`、`hardware`、`baseline` 与 `ample`。星图的指针交互按 `PointerEvent` 的可用性绑定，缺失时保留漂浮与键盘微调。
3. 未知地址页面改为自包含。原先引用站点根下的样式、脚本与图标，项目站点形式（`/<repository>/`）下会全部取不到；现在样式内联，页面不请求站点资源，链接先按相对地址写，再由脚本逐级向上探测站点根并改写，`file://` 打开与探测失败时保持相对地址。判定说明同步写入内容规划、项目规划、设计说明与文章正文。

第二阶段的核对结果：十项检查全部通过。项目子目录下的深层未知地址，九个链接全部指向 `/Qi-Blog-YM/`；域名根下的深层未知地址指向根；`file://` 打开保持相对地址；标题计算字号 30.4 像素，说明内联样式生效；功能机 UA 判为 `minimal`、原因为 `legacy-ua`、兜底样式表挂载、跳转链接可见高度大于零、主题按钮隐藏、导航常驻；受限 UA 记为 `constrained-ua`；缺少 `PointerEvent` 时档位不变、漂浮继续、方向键微调使节点位置由 12% 移到 13.5%。全程无页面脚本错误。
