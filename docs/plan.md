# 项目规划

本文档确立个人博客作品的技术底座、目录结构与开发顺序。开发顺序遵循一条原则：功能与流畅性优先，视觉打磨置于末位。

## 一、技术底座

### 选型结果

| 层次 | 选型 | 引入方式 |
| --- | --- | --- |
| 页面结构 | 语义化 HTML5，静态多页面 | 无 |
| 样式 | 原生 CSS，自建设计令牌与组件类 | 无 |
| 脚本 | 原生 JavaScript，classic script | 无 |
| 图标 | Lucide | SVG 内联，按需复制 |
| 代码高亮 | highlight.js | 文章页本地引入 |
| 星河背景 | CSS 渐变与关键帧动画 | 无 |
| 构建 | 无构建步骤 | 无 |

### 采用依据

1. 流畅性。无框架运行时，首屏开销集中在 HTML 与 CSS。动画只使用 transform 与 opacity，交由合成层处理，重排与重绘的出现面降到最小。
2. 兼容性。classic script 与相对地址的组合，使页面在 file:// 与静态托管两种环境下都能运行。ES module 在 file:// 下受跨源策略限制，外部模块与本地区块数据读取都会失败，因此不作为加载方式。
3. 赛事契合。赛事点名 HTML、CSS、JavaScript 三项技术，原生实现与技术说明一一对应。
4. 环境契合。本机 Node 位于 Windows 侧，构建链调用成本偏高，无构建方案在开发与验证环节更轻便。

### 未采用项

| 方案 | 未采用原因 |
| --- | --- |
| Vue、React、Svelte | 博客交互密度低，运行时开销超过收益 |
| Element Plus、Ant Design、Bootstrap | 默认观感趋同，体积与创意评分不匹配 |
| Tailwind CSS | 要取得可接受的体积，必须引入构建步骤 |
| Astro | 构建产物使用绝对地址，file:// 打开时资源加载失败 |

## 三、开发阶段

### 阶段一 技术底座

确定选型、目录结构与脚手架，建立开发与验证方式。产出为本文档与可运行的页面骨架。

验收标准：以 file:// 与静态托管两种方式打开首页，样式、脚本与主题切换均正常。

### 阶段二 内容与栏目结构

确定导航栏目、页面清单与内容组织方式。文章内容以静态 HTML 编写，不使用运行时解析，避免首屏出现内容闪现。

验收标准：页面清单与栏目关系完整，每页的内容职责清晰。

### 阶段三 页面与导航骨架

搭建各页面的语义化结构，完成响应式布局与导航，处理共享头部与底部的重复片段。

验收标准：375、768、1440 三种宽度下无横向滚动；键盘可以完成全部导航。

### 阶段四 内容模块与交互

实现文章列表与详情、作品陈列、个人介绍等模块，补充滚动出现动画与导航高亮。

验收标准：各页面内容完整、链接互通，滚动过程无掉帧。

### 阶段五 性能、兼容性与无障碍

在目标浏览器中逐项验证，核对首屏体积与渲染指标，检查焦点样式、ARIA 属性与颜色对比度。

验收标准：预算表内各项达标，Lighthouse 无障碍评分不低于 90。

### 阶段六 视觉打磨

调整设计令牌的配色、字体与间距节奏，补充星河主题的纹理与装饰元素。本阶段处于末位，前序阶段未完成时不进入。

验收标准：整站观感统一，各断点下无破版。

### 阶段七 打包与交付

核对资源体积，按赛事要求命名压缩包，撰写包含设计理念与技术实现的设计说明。

验收标准：解压后双击 index.html 即可完整浏览。

## 四、性能与兼容性预算

| 维度 | 目标 |
| --- | --- |
| 首屏关键资源（HTML 与 CSS） | 未压缩 120 KB 以内 |
| JavaScript 体积 | 未压缩 40 KB 以内 |
| 单页 DOM 节点 | 1500 以内 |
| 累计布局偏移 | 接近于零，媒体元素标注宽高 |
| 目标浏览器 | Chrome 与 Edge 105 以上、Firefox 110 以上、Safari 15.4 以上 |
| 响应式断点 | 375、768、1024、1440 |
| 动画属性 | 仅 transform 与 opacity |

## 五、验证方式

1. 静态托管。在项目根目录启动静态服务器，浏览器访问本地端口。
2. 本地文件。以 file:// 打开 index.html，核对样式、脚本与主题切换。
3. 浏览器矩阵。在 Chrome、Edge、Firefox 中抽查布局与交互。
4. 无脚本核对。关闭 JavaScript 后确认正文可读、导航可用。
5. 无障碍核对。Lighthouse 检查与键盘操作复核。
