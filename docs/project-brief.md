# 项目说明

## 背景

本项目为计算机学院企源开发者协会举办的个人博客创意设计大赛参赛作品。

## 内容规划

博客内容按三个部分组织。

1. 个人介绍：学习方向、技术兴趣与联系方式。
2. 文章：按主题或时间组织，提供列表页与详情页两种视图。
3. 作品：陈列项目与实验，附技术栈与仓库链接。

栏目结构在实现阶段确定，本文档随进度更新。

## 设计方向

主题意象为星河。配色、字体、版式与动效四个层面围绕这一意象展开，形成统一的视觉语言。以下为方向确定前的约束与原则。

配色与星河意象呼应，同时保证正文文字与底色的对比度满足连续阅读的要求。

字族数量控制在一到两种，标题与正文通过字重、字号与字距拉开层级差异。

栅格与留白节奏在整站保持一致，正文行宽控制在适合连续阅读的区间。

动效服务于叙事与反馈，用于首屏氛围、滚动过渡与交互反馈，避免影响操作响应。

## 技术方向

产出为静态文件，部署与分发成本低。

首屏体积与渲染性能作为约束条件，逐一评估组件与动效库的引入必要性。

语义化标签、键盘可达性与色彩对比度在实现阶段纳入检查。

## 交付形态

页面源码、静态资源与说明文档一并打包。
