文章页的阅读增强：按需渲染与代码块操作

2026-10-13阅读体验

  • 阅读体验
  • 渲染性能
  • 无障碍

列表页与文章页共用同一套样式，差别集中在正文。额外的阅读能力放在 article.css 与 reader.js 两份文件里，只在文章详情页加载，其余页面的首屏请求不受影响。

目录与阅读进度

目录由脚本扫描正文的小节标题生成，标题不足三条时不予生成，避免为一段短文制造冗余结构。当前所处的小节由观察器在视口中判断，并用 aria-current 标注。

阅读进度条固定在页面顶部，高度 2 像素，位移交给 transform: scaleX()；滚动回调合并到 requestAnimationFrame 内，一次滚动最多写入一次样式。回到顶部的按钮在纵向滚动超过 400 像素后出现，动效档位受限时改为瞬时定位。

代码块的操作

每个代码块会补一条工具条，显示语言、折叠与复制。折叠阈值取 16 行，超过的部分默认收起，按钮的 aria-expanded 随状态同步。

复制优先使用异步剪贴板接口，接口不可用时回退到临时文本域与 execCommand，这条回退在以本地文件打开时同样有效。复制结果由独立的状态区播报，读屏软件可以获取反馈。

代码块横向可滚动，因此补上了 tabindex，键盘能够进入并查看长行。下面两段文字取自 reader.js。

function enhanceBlock(pre) {
  /* 代码块可横向滚动，需要能通过键盘到达 */
  if (!pre.getAttribute('tabindex')) {
    pre.setAttribute('tabindex', '0');
  }

  var source = code ? code.textContent : pre.textContent;
  var lines = countLines(source);

  if (lines > FOLD_MIN_LINES) {
    var toggle = document.createElement('button');
    toggle.type = 'button';
    toggle.className = 'code-action';
    toggle.textContent = '展开';
    toggle.setAttribute('aria-expanded', 'false');
    toggle.addEventListener('click', function () {
      var folded = wrapper.getAttribute('data-folded') === 'true';
      wrapper.setAttribute('data-folded', folded ? 'false' : 'true');
      toggle.setAttribute('aria-expanded', folded ? 'true' : 'false');
      toggle.textContent = folded ? '收起' : '展开';
    });
    wrapper.setAttribute('data-folded', 'true');
    bar.appendChild(toggle);
  }
}

function copyText(value, onDone) {
  function fallback() {
    var area = document.createElement('textarea');
    area.value = value;
    area.setAttribute('readonly', 'readonly');
    area.style.position = 'fixed';
    area.style.top = '-1000px';
    document.body.appendChild(area);
    area.select();
    try {
      document.execCommand('copy');
      onDone();
    } catch (error) {
      /* 复制不可用时保留原文 */
    }
    document.body.removeChild(area);
  }

  if (navigator.clipboard && typeof navigator.clipboard.writeText === 'function') {
    navigator.clipboard.writeText(value).then(onDone, fallback);
    return;
  }
  fallback();
}

公式与代码高亮的按需加载

两份渲染库都不进入首屏请求队列。代码高亮只在页面存在代码块时请求，公式渲染只在正文确实命中公式分隔符时请求，两者都要求当前档位允许按需脚本。

判定公式的方式是读取正文的纯文本，跳过 pre 与 code 内部的文本后再匹配分隔符，因此代码里的美元符号不会造成误判。行内公式写作 $O(n\log n)$ 这种形式，独立成段的公式如下。

$$ \int_{-\infty}^{\infty} e^{-x^{2}}\,\mathrm{d}x = \sqrt{\pi} $$

KaTeX 的脚本约 273 KB、字体约 296 KB，highlight.js 约 129 KB，三者都只在命中内容时进入请求队列。命中的内容越少，被跳过的资源越多。

字号控制

字号分为小、中、大三档，改动的是正文基准字号，小节标题、代码与公式按同一比例缩放，避免只放大正文造成层级错位。选择结果写入 localStorage，存储不可用时只影响当前会话。

小结

阅读增强的取舍标准是：对阅读有直接帮助的能力保留，代价偏大的渲染库按内容出现情况加载，低端档位整体让位给正文。
