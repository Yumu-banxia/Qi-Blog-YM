文章页的阅读增强：按需渲染与代码块操作

2026-10-13阅读体验

  • 阅读体验
  • 渲染性能
  • 无障碍

写完第一篇文章才发现，正文里的东西比正文本身麻烦：一段三十来行的代码在窄屏上被拉得很长，几条公式要等渲染库加载完才出现。阅读增强这一块就是为这些情况写的，代码放在 article.css 与 reader.js，只在文章详情页加载。

目录与进度条

目录是脚本扫正文的二级、三级标题拼出来的，标题不到三条就不生成——短文配目录反而累赘。当前所在的小节由观察器判断，命中后标 aria-current。

顶部那条进度线高两像素，位移交给 transform: scaleX()，滚动回调塞进 requestAnimationFrame，一次滚动最多写一次样式。回到顶部的按钮在纵向滚过 400 像素后出现；设备被判定不适合动效时，它改成瞬时跳转。

代码块

每个代码块补一条工具条：语言、折叠、复制。超过 16 行默认收起，按钮上写清楚还剩多少行，展开状态同步到 aria-expanded。

复制走异步剪贴板接口，失败时退回临时文本域加 execCommand，本地文件打开时这条回退用得上。复制结果交给一个独立状态区播报，读屏软件能听到。

代码块横向能滚，所以补了 tabindex，键盘可以进去看长行。折叠时只裁纵向，横向照样能滚——早先的写法把 overflow 整个设成 hidden，长行只能看到左边一截，这个错很久之后才修。

function enhanceBlock(pre) {
  /* 代码块可横向滚动，需要能通过键盘到达 */
  if (!pre.getAttribute('tabindex')) {
    pre.setAttribute('tabindex', '0');
  }

  var source = code ? code.textContent : pre.textContent;
  var lines = countLines(source);

  if (lines > FOLD_MIN_LINES) {
    var toggle = document.createElement('button');
    toggle.type = 'button';
    toggle.className = 'code-action';
    toggle.textContent = '展开';
    toggle.setAttribute('aria-expanded', 'false');
    toggle.addEventListener('click', function () {
      var folded = wrapper.getAttribute('data-folded') === 'true';
      wrapper.setAttribute('data-folded', folded ? 'false' : 'true');
      toggle.setAttribute('aria-expanded', folded ? 'true' : 'false');
      toggle.textContent = folded ? '收起' : '展开';
    });
    wrapper.setAttribute('data-folded', 'true');
    bar.appendChild(toggle);
  }
}

function copyText(value, onDone) {
  function fallback() {
    var area = document.createElement('textarea');
    area.value = value;
    area.setAttribute('readonly', 'readonly');
    area.style.position = 'fixed';
    area.style.top = '-1000px';
    document.body.appendChild(area);
    area.select();
    try {
      document.execCommand('copy');
      onDone();
    } catch (error) {
      /* 复制不可用时保留原文 */
    }
    document.body.removeChild(area);
  }

  if (navigator.clipboard && typeof navigator.clipboard.writeText === 'function') {
    navigator.clipboard.writeText(value).then(onDone, fallback);
    return;
  }
  fallback();
}

公式与高亮按需加载

两份渲染库都不进首屏。代码高亮只在页面真有代码块时请求，公式渲染只在正文确实出现分隔符时请求。判断公式的办法是读正文纯文本，遇到 pre 与 code 就跳过，所以代码里的美元符号不会误判。行内公式写成 $O(n\log n)$ 这样，独立成段的公式是下面这条。

$ \int_{-\infty}^{\infty} e^{-x^{2}}\,\mathrm{d}x = \sqrt{\pi} $

KaTeX 脚本约 273 KB、字体约 296 KB，highlight.js 约 129 KB。页面上一行代码都没有的时候，这些数字就是零。

字号

小、中、大三档改的是正文基准字号，小节标题、代码、公式按同一比例跟着缩放。早先只放大正文，标题反而显小，层级看着别扭。选择存在 localStorage，存不了就只影响这次会话。

还没做的

代码块没有行号，也做不了差异对比；折叠阈值写死 16 行，长行短行的观感差别不小。这些等文章多起来再补。
