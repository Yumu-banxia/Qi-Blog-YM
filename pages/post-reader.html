文章页阅读增强：目录、代码块与公式

2026-10-13阅读体验

  • 阅读体验
  • 渲染性能
  • 无障碍

文章详情页的阅读增强包括章节目录、阅读进度、代码块操作、公式排版与字号设置。样式和交互分别由 article.css 与 reader.js 承担；代码高亮和公式库仅在正文包含对应内容时按需加载。

目录生成与章节定位

目录由脚本扫描正文的二级与三级标题生成，标题少于三条时不渲染。当前小节由观察器判定，命中项标注 aria-current。

阅读进度与返回顶部

顶部进度线高 2 像素，位移通过 transform: scaleX() 完成。滚动回调由 requestAnimationFrame 合并，每帧最多写入一次样式。返回顶部按钮在纵向滚动超过 400 像素后出现；访问端被判定为不适合动效时，按钮改为瞬时跳转。

代码块复制与折叠

每个代码块附加一条工具条，提供语言标识、折叠与复制。代码超过 16 行时默认折叠，按钮注明剩余行数，展开状态同步至 aria-expanded。

复制优先使用异步剪贴板接口，失败时回退到临时文本域与 execCommand，该路径在 file:// 环境下仍然有效。复制结果由独立状态区播报，读屏软件可以获取。

折叠、滚动与键盘操作

代码块使用浏览器原生纵横向滚动，并补充 tabindex="0" 供键盘访问。收起窗口最多显示 16 行，并会随较矮视口缩小；展开后按代码内容增高，窗口上限为视口高度的 90% 与 48rem 两者中的较小值。超出窗口的代码仍可在块内滚动。

按钮事件切换代码块状态、同步 aria-expanded，并将局部滚动位置归零。以下片段节选自 reader.js。

toggle.addEventListener('click', function () {
  var folded = wrapper.getAttribute('data-folded') === 'true';
  wrapper.setAttribute('data-folded', folded ? 'false' : 'true');
  toggle.setAttribute('aria-expanded', folded ? 'true' : 'false');
  toggle.textContent = folded ? '收起' : '展开剩余 ' + restLines + ' 行';
  pre.scrollTop = 0;
});

公式与高亮的按需加载

两份渲染库都不进入首屏。代码高亮仅在页面存在代码块时请求，公式渲染仅在正文出现分隔符时请求。公式检测读取正文纯文本，遇到 pre 与 code 元素即跳过，因此代码中的美元符号不会触发误判。行内公式写作 $O(n\log n)$，独立公式使用双美元符号。

$ \int_{-\infty}^{\infty} e^{-x^{2}}\,\mathrm{d}x = \sqrt{\pi} $

KaTeX 的脚本与样式合计约 292 KB，字体约 254 KB；highlight.js 约 126 KB。页面没有代码块或公式时，这些资源不产生请求。

字号设置与偏好保存

字号分为小、中、大三档，正文、小节标题、代码与公式按同一比例缩放。偏好保存在 localStorage；存储不可用时仅对当前会话生效。

代码块功能边界

代码块目前支持复制、折叠与局部滚动，尚未提供行号和差异对比。折叠阈值固定为 16 行，后续可依据文章中的代码长度评估调整。
