兼顾功能机与现代设备：访问端能力分级

2026-10-12兼容性

  • 兼容性
  • 渐进增强
  • 降级策略

Nokia 2700c 核验时，页面主布局失效，正文区域被压缩。项目据此加入四档能力分级，根据 User-Agent、硬件、网络与运行时接口控制样式和脚本。

能力判定依据

判定脚本位于 <head> 内并同步执行，结果写入根元素的 data-cap 属性。样式与后续脚本读取同一属性，不再各自判断。信号来源分为三组。

User-Agent 是第一组信号。包含 MIDP、Symbian、Opera Mini 或 Trident 等特征时，访问端归入最低档；内核较新但硬件受限的机型，例如早期 Android、UC 浏览器与 MIUI 内置浏览器，归入受限档。

第二组为硬件与网络状态，包括逻辑核心数、设备内存、省流模式与连接类型。2G 级连接归入受限档。

第三组为运行时接口，按核心与增强两类拆分。核心接口包含 querySelector、addEventListener、CSS.supports('--probe: 0')、matchMedia 与 requestAnimationFrame，任一缺失即判最低档；增强接口包含 IntersectionObserver、ResizeObserver 与 PointerEvent，缺失时只关闭对应功能，档位保持不变。

四档能力与启用范围

各档的判定条件与启用功能
档位 判定条件 启用功能
high 逻辑核数 8 以上，内存 4 GB 以上，且未偏好减少动态效果 全部动效与增强
medium 未命中其他条件的现代设备 动效、模糊、按需脚本
low 受限 UA、双核以内、内存 1 GB 以内、省流模式或 2G 级连接 静态内容与基础表现
minimal 功能机 UA，或缺少 querySelector、自定义属性等核心接口 静态内容

样式与脚本的分级控制

样式通过属性选择器读取档位。受限档关闭页头模糊；最低档将导航改为常驻排列，隐藏搜索与主题按钮，停止动画与过渡，并让跳转主内容的链接常驻可见。

脚本通过 Capability.allow(name) 查询单项能力，未获允许时不发起请求，避免下载后再判断。滚动入场效果依赖 IntersectionObserver，接口缺失时待入场元素保持可见；星图的指针交互依赖 PointerEvent，接口缺失时保留漂浮与键盘微调。

var coreRuntime = {
  querySelector: typeof document.querySelector === 'function',
  events: typeof window.addEventListener === 'function',
  customProperties: cssSupports('--probe: 0'),
  matchMedia: typeof window.matchMedia === 'function',
  animationFrame: typeof window.requestAnimationFrame === 'function'
};

/* 逐项检查上面的接口，记下第一个缺失项 */
var missingCore = '';

var tier = 'medium';
var reason = 'baseline';

if (legacyUA || missingCore) {
  tier = 'minimal';
  reason = legacyUA ? 'legacy-ua' : 'limited-runtime';
} else if (CONSTRAINED_PATTERN.test(ua)) {
  tier = 'low';
  reason = 'constrained-ua';
} else if (saveData || slowNetwork) {
  tier = 'low';
  reason = 'network';
} else if ((cores > 0 && cores <= 2) || (memory > 0 && memory <= 1)) {
  tier = 'low';
  reason = 'hardware';
} else if (cores >= 8 && memory >= 4 && !prefersReducedMotion) {
  tier = 'high';
  reason = 'ample';
}

var features = {
  motion: (tier === 'high' || tier === 'medium') && !prefersReducedMotion,
  optionalScripts: tier === 'high' || tier === 'medium'
};

root.setAttribute('data-cap', tier);
root.setAttribute('data-cap-reason', reason);

最低档位的基础样式

仅有静态内容尚不足以保证可读性。缺少自定义属性与弹性布局支持的浏览器无法正确解析主样式表，最低档位因此追加一份兜底样式：不使用自定义属性、flex 与 grid，正文 16 像素、行高 1.6，导航恢复为行内排列。

根元素上的 data-cap-reason 记录触发降级的信号，取值为 legacy-ua、limited-runtime、constrained-ua、network 与 hardware，用于在真机上定位判定结果。

阈值与验证范围

内存与核心数阈值来自经验估计，目前仅在数台常见设备上核对；功能机实测只有 Nokia 2700c。现有样本不足以证明这些阈值适用于更多机型。
